Группа

Présent de l'indicatif

Настоящее время — самое основное время во французском

Когда используется

✓ Регулярные действия и привычки — Je mange à midi.
✓ Факты и общие истины — Le soleil se lève à l'est.
✓ Действие прямо сейчас — Je lis un livre en ce moment.
✓ Будущее, которое точно произойдёт — Demain, je pars à Paris.

Образование — глаголы 1-й группы (-ER)

инфинитив без -ER + окончание
parler → parl-
je parle   tu parles   il/elle parle
nous parlons   vous parlez   ils parlent

Образование — глаголы 2-й группы (-IR)

инфинитив без -IR + окончание (+ -iss- во мн.ч.)
finir → fin-
je finis   tu finis   il/elle finit
nous finissons   vous finissez   ils finissent

Образование — глаголы 3-й группы (-RE)

инфинитив без -RE + окончание
vendre → vend-
je vends   tu vends   il/elle vend—
nous vendons   vous vendez   ils vendent

Примеры

  • Je travaille tous les jours.Я работаю каждый день.
  • Elle finit son travail à 18h.Она заканчивает работу в 18:00.
  • Nous vendons des livres.Мы продаём книги.
  • Ils parlent français.Они говорят по-французски.

Passé composé

Прошедшее время — завершённые действия

Когда используется

✓ Однократное завершённое действие в прошлом — J'ai mangé une pomme.
✓ Действие с точным указанием времени — Hier, il est parti à 8h.
✓ Последовательность действий — Je suis entré, j'ai vu, j'ai compris.
✗ НЕ для состояний или привычек — там Imparfait.

Образование = avoir/être + participe passé

AVOIR + participe passé (большинство глаголов)
J'ai parlé   tu as fini   il a vendu
nous avons   vous avez   ils ont
ÊTRE + participe passé (движение и рефлексивы)
je suis allé(e)   il est venu   elle est partie
Глаголы с être: aller, venir, partir, arriver, entrer, sortir,
naître, mourir, rester, tomber, monter, descendre, passer, retourner

Participe passé — как образуется

-ER глаголы: parler → parlé
-IR глаголы: finir → fini
-RE глаголы: vendre → vendu
Неправильные: être→été, avoir→eu, faire→fait, voir→vu, venir→venu

Примеры

  • J'ai mangé une baguette ce matin.Я съел багет этим утром.
  • Elle est arrivée à Paris hier.Она приехала в Париж вчера.
  • Nous avons fini le projet.Мы завершили проект.
  • Ils sont partis tôt.Они ушли рано.

Imparfait

Незавершённое прошлое — описания, привычки, фон

Когда используется

✓ Прошлые привычки и повторяющиеся действия — Chaque été, nous allions à la mer.
✓ Описания состояний в прошлом — Il faisait beau. Elle était triste.
✓ Фоновое действие при passé composé — Je dormais quand il est arrivé.
✓ Вежливые просьбы — Je voulais vous demander...

Образование — универсальное правило

Берём nous présent → убираем -ons → добавляем окончание
parler: nous parlons → parl- → je parlais
finir: nous finissons → finiss- → je finissais
faire: nous faisons → fais- → je faisais
je -ais   tu -ais   il/elle -ait
nous -ions   vous -iez   ils -aient
Исключение: être → j'étais (основа ét-)

Passé composé vs Imparfait — главное отличие

Passé composé = что случилось (действие)
Imparfait = как было (состояние, фон)
Il pleuvait quand je suis sorti. — Шёл дождь (фон), когда я вышел (действие).

Примеры

  • Quand j'étais enfant, je jouais au foot.Когда я был ребёнком, я играл в футбол.
  • Il faisait froid et il neigeait.Было холодно и шёл снег.
  • Je lisais quand tu m'as appelé.Я читал, когда ты мне позвонил.

Futur simple

Будущее время — планы, обещания, прогнозы

Когда используется

✓ Планы и обещания — Je reviendrai demain.
✓ Предсказания и прогнозы — Il fera beau demain.
✓ После si + présent — Si tu viens, nous irons au cinéma.
✓ Формальный стиль — Le président parlera à 20h.

Образование — почти всегда от инфинитива

инфинитив (для -RE: без последней -e) + окончание avoir
parler → parlerai
finir → finirai
vendre → vendrai
je -ai   tu -as   il/elle -a
nous -ons   vous -ez   ils -ont

Неправильные основы — нужно запомнить

être → ser-   avoir → aur-   aller → ir-
faire → fer-   venir → viendr-   voir → verr-
pouvoir → pourr-   vouloir → voudr-   savoir → saur-

Примеры

  • Demain, je partirai tôt.Завтра я уйду рано.
  • Elle sera médecin.Она будет врачом.
  • Nous irons en France l'été prochain.Мы поедем во Францию следующим летом.

Неправильные глаголы

Не поддаются стандартным правилам — но у них есть группы!

Группы по схожести спряжения

Группа ÊTRE / AVOIR

être, avoir

Базовые глаголы. Спрягаются полностью нерегулярно — просто заучить.

Группа ALLER

aller, s'en aller

je vais, tu vas, il va, nous allons, vous allez, ils vont. Корень меняется радикально.

Группа VENIR / TENIR

venir, devenir, revenir, tenir, obtenir, appartenir, contenir

je viens/tiens, nous venons/tenons, ils viennent/tiennent. Закономерность: -iens/-ient/-iennent.

Группа PRENDRE

prendre, comprendre, apprendre, reprendre, surprendre

je prends, nous prenons, ils prennent. Во мн.ч. — удвоение n.

Группа PARTIR / SORTIR

partir, sortir, dormir, servir, sentir, mentir

je pars/sors, nous partons/sortons. В ед.ч. отбрасывается конечный согласный основы.

Группа VOIR / CROIRE

voir, prévoir, revoir, croire

je vois, nous voyons, ils voient. Основа меняется: voi-/voy-.

Группа FAIRE

faire, défaire, refaire, satisfaire

je fais, nous faisons, vous faites, ils font. Vous faites — исключение из правила -ez!

Группа METTRE / BATTRE

mettre, permettre, promettre, battre, combattre

je mets, nous mettons. В ед.ч. только одно t: je mets, il met.

Группа ÉCRIRE / LIRE

écrire, décrire, inscrire, lire, élire, relire

j'écris/lis, nous écrivons/lisons. Схожий паттерн уменьшения основы.

Группа POUVOIR / VOULOIR / SAVOIR

pouvoir, vouloir, savoir, valoir

Модальные. je peux/veux/sais. Особенность: je peux → puis-je? (инверсия).

Группа OUVRIR / OFFRIR

ouvrir, couvrir, découvrir, offrir, souffrir

Спрягаются как -ER глаголы! j'ouvre, tu ouvres — без -s в 1-м лице.

Groupe CONNAÎTRE / NAÎTRE

connaître, reconnaître, paraître, naître

je connais, il connaît (с circonflexe перед t). Основа: connaiss- во мн.ч.

Verbes pronominaux

Возвратные глаголы — действие направлено на самого субъекта

Что это такое

Возвратные глаголы используют местоимение me / te / se / nous / vous / se перед глаголом.
se laver = мыться (буквально: мыть себя)
s'appeler = называться / зваться
В инфинитиве всегда стоит se (или s' перед гласной).

Спряжение в présent

se lever — вставать
je me lève   tu te lèves   il se lève
nous nous levons   vous vous levez   ils se lèvent
s'appeler — называться (перед гласной: s')
je m'appelle   tu t'appelles   il s'appelle
nous nous appelons   vous vous appelez   ils s'appellent

Passé composé — всегда с ÊTRE

Все возвратные глаголы образуют passé composé с être.
Причастие согласуется с подлежащим в роде и числе:
Il s'est levé. — Elle s'est levée. — Ils se sont levés.
je me suis levé(e)
tu t'es levé(e)
il s'est levé  /  elle s'est levée
nous nous sommes levé(e)s
vous vous êtes levé(e)(s)
ils se sont levés  /  elles se sont levées

Отрицание

ne ... pas обрамляет местоимение + глагол
Je ne me lève pas tôt.
Il ne s'est pas levé.

Три типа возвратных глаголов

Собственно возвратные

Действие на себя.
se laver, se coiffer, s'habiller, se regarder

Взаимные

Действие друг на друга.
se parler, se voir, se rencontrer, s'aimer

Идиоматические

Особый смысл.
s'en aller (уходить), se passer (происходить), se souvenir (помнить)

Примеры

  • Je me réveille à 7h.Я просыпаюсь в 7 часов.
  • Elle s'est couchée tard.Она легла поздно.
  • Nous nous souvenons de toi.Мы тебя помним.
  • Ils se sont mariés en juin.Они поженились в июне.
  • Tu te dépêches?Ты торопишься?
  • Comment vous appelez-vous?Как вас зовут?
